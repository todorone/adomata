# Meta only for v1

Adomata bundles media buying, SMM, and automation into one product. Rather than build a generic multi-platform abstraction up front, v1 targets Meta (Facebook + Instagram) only — its API covers both paid (Ads Manager) and organic (Pages/Instagram) under one surface, enough to validate the combined product without guessing at a "Channel" abstraction we'd likely redesign once a second platform (Google, TikTok, LinkedIn) is actually in scope.
