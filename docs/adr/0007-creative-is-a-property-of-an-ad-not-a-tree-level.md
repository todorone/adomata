# Creative is a property of an Ad, not a tree level

The owner's own interview describes "reaching creative level," inviting the reading that Creative is a fifth tree level below Ad, sitting alongside Campaign → Ad Set → Ad the way Ad Set lists multiple Ads. Meta's own object model says otherwise: an Ad has exactly one `AdCreative`, and a carousel or Advantage+ asset-feed ad carries several assets *inside* that one creative (`asset_feed_spec`'s images/videos/copy/links, or a carousel's `child_attachments`) rather than as multiple sibling creative objects. Adomata's fleet board tree therefore stops at four levels (Ad Account → Campaign → Ad Set → Ad); Creative is rendered by expanding an Ad row in place — potentially into a carousel strip or an asset-variant list — not as a fifth level with its own independent expand/collapse and child count. This matches Meta's actual API shape and avoids building list/pagination infrastructure for something that is always cardinality-one at the Ad boundary, even though its internal content can be a set.
