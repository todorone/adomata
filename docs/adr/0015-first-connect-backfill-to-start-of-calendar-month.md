# First-connect backfill reaches back to the start of the current calendar month

When an Ad Account is newly connected, its first sync backfills daily Insights history from the 1st of the current calendar month, not just forward from the connection moment. This was decided while resolving [issue #12](https://github.com/todorone/adomata/issues/12): [ADR 0002](0002-budget-scoped-to-client.md) tracks a Client's Budget Exhausted state against its *actual* spend across all its Ad Accounts for the calendar month, so an Ad Account connected on, say, the 20th would silently under-report that Client's month-to-date spend for the first 19 days if backfill started at the connection date — a Budget could already be exhausted in reality with the board showing otherwise. Backfilling to the 1st of the month is the minimum depth Budget Exhausted needs to mean what it claims, and it's a natural boundary tied to an existing rule rather than an arbitrary trailing window.
