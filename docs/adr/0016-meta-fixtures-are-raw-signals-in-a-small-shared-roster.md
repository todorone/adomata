# Meta fixtures are raw-signal combinations, a small fixed roster, shared by dev seeding and tests

The fake Meta layer ([ADR 0014](0014-meta-api-faked-via-network-interception.md)) needs concrete fixture data, decided as one shape rather than case-by-case:

- **Defined by raw Meta signal, not target color.** Fixture accounts are authored as raw API-shaped combinations (`account_status`, `disable_reason`, `balance`, `is_prepay_account`, `funding_source_type`) — the same fields [issue #3](https://github.com/todorone/adomata/issues/3) wants covered from a real Business Manager — never as a hand-set `healthColor`. [Issue #11](https://github.com/todorone/adomata/issues/11) (the green/yellow/red mapping) is still open; defining fixtures by raw signal decouples this work from that ticket in both directions, and turns the fixtures into a test of whatever mapping #11 lands on, rather than a restatement of it.
- **A small fixed roster (roughly 5–8 accounts)**, not a fleet-scale simulation. Today's testing need is correctness (health mapping, rollups, freshness display), not volume — "rendering at real scale" is explicitly unspecified elsewhere on [the map](https://github.com/todorone/adomata/issues/2) pending a virtualization design, so a large generated fleet would be scoped ahead of the ticket that needs it.
- **Fixed per-account fault behavior for transport-level conditions.** A couple of roster accounts are permanently "the throttled one" / "the revoked one," returning the corresponding Meta error shape and headers on every call. This covers today's need (does the sync/board correctly handle a throttled or revoked account) without adding a runtime control channel; testing *transitions* (recovery from throttle) is deferred until a ticket actually needs it.
- **One shared fixture module**, imported by both a dev-only DB seed script (which inserts the matching Client/Ad Account rows into Adomata's own database under the same ids) and the integration tests. A developer's local Fleet Board and the test suite read from the same roster by construction, so they cannot silently drift apart.
