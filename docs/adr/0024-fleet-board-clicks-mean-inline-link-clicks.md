# Fleet Board Clicks mean Meta inline link clicks

The Clicks KPI stores Meta's `inline_link_clicks`, not its broader `clicks` field, and CTR is re-derived as summed inline link clicks divided by summed impressions. Meta's broad field includes likes, comments, shares, and image opens; counting those would overstate the destination-oriented performance that a media buyer expects from Clicks. This deliberately inherits Meta's fixed one-day-click attribution behavior for `inline_link_clicks`.
