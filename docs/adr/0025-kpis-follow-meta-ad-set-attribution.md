# Attributed KPIs follow each Ad Set's current Meta setting

CPA and ROAS follow each Ad Set's current attribution setting in Meta Ads Manager rather than a Fleet Board-wide attribution window. This keeps Adomata aligned with the Meta UI where buyers investigate and act, and matches Meta's attribution-unification behavior, at the cost of strict comparability when Ad Sets use different windows. Historical daily Insights remain inside the 28-day Reconciliation Window because attributed results can settle or change after the original day.
