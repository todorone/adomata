# Fleet Board ships three complete views for evaluation

The Fleet Board ships Tree, Control Room, and Signals as switchable, functionally complete views over one shared data and domain layer, superseding [ADR 0021](0021-fleet-board-is-one-tree-table-with-a-depth-dial-over-row-expansion.md)'s single Tree-view decision. All three expose the same Time Range, Metric Selection, filtering and sorting inputs, freshness, hierarchy depth, detail access, and Creative data, but express them through a hierarchy table, fleet rail plus selected-account detail, and operational lanes with expandable cards respectively. Signals uses Needs Attention, Postpay, and Active lanes rather than grouping raw colors; this keeps a lost Meta connection in the attention workflow while preserving yellow as neutral, while pending accounts remain outside the board during Initial Import ([ADR 0032](0032-sync-runs-are-durable-and-invisible-when-healthy.md)). Tree remains the bare-URL default and the active view is URL-encoded. After user interviews, a separate evidence-based decision will promote the strongest default, retain only genuinely distinct secondary workflows, and remove redundant views; shared behavior keeps that deletion cheap.
